# Milan Špaček

> Programátor a lektor • MicroPython & ESP32 • Robotika pro děti • Autor projektu **ESP IDE**

Jsem vývojář z Česka. Stavím otevřené nástroje pro výuku programování a robotiky, převážně pomocí **MicroPythonu** a **ESP32**. Vedu kroužky pro děti (10–15 let), kde kombinujeme **Blockly**, **Python**, 3D tisk a jednoduchou elektroniku. Mým cílem je, aby z prototypů vznikaly **reálné, funkční věci** – roboti na dálkové ovládání, line‑followeři, minisumo a další projekty za použití vývojového prostředí **ESP IDE**.

---

## 🔭 Na čem trávím nejvíce času ?
- **ESP IDE** – vizuální i textové vývojové prostředí pro MicroPython (Blockly + ACE editor).  
  - Desktop: **Electron** app pro Windows, Linux a macOS  
  - Připojení: **WebSerial** (USB), **Web Bluetooth LE** (BLE REPL na ESP32)  
  - Správce souborů, instalátor firmware a knihoven, dynamický toolbox, rozšíření bloků
- **Flashovací nástroj** – webový instalátor čistého MicroPythonu pro ESP i RP2 (UF2) + následná instalace knihoven

---

## 🧰 Technologie a nástroje
**Jazyky:** Python, MicroPython, C/C++, JavaScript/TypeScript, HTML/CSS  
**MCU / HW:** ESP32/ESP32‑C3/ESP32‑S3, ESP8266, RP2040, senzory (DHT, VL53L0X, MPU6050…), serva, DC motory, NeoPixel  
**Komunikace:** WebSerial, Web Bluetooth LE, ESP‑NOW, HTTP/REST  
**Další:** 3D tisk, Tinkercad, základy KiCad, fotografie a grafika pro výuku
